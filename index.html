Roadmap Belajar Lengkap

Kurikulum Berbasis Kebutuhan Industri

Disusun dari tingkat pemula tanpa pengalaman koding hingga tingkat mahir, mencakup fondasi dasar web hingga jembatan menuju React modern.

MODUL 01 • 2 MINGGU Fondasi Utama

HTML5 Semantics, Modern CSS3 & Responsive Layout

Memahami struktur website yang SEO-friendly dan standar aksesibilitas (a11y), dipadukan dengan teknik tata letak modern CSS.

  • HTML5 Semantic Elements (header, nav, main, section, footer)
  • CSS Box Model, Flexbox Architecture, dan CSS Grid System
  • Media Queries untuk Mobile-First Responsive Design
  • CSS Custom Properties (Variables) & Modern Typography
  • Studi Kasus: Membangun Responsive Landing Page Restoran
MODUL 02 • 2 MINGGU UI Framework

Bootstrap 5.3 Mastery & Professional UI Components

Mempercepat proses pengembangan antarmuka website dengan framework terpopuler di dunia tanpa kehilangan kemampuan kustomisasi.

  • 12-Column Responsive Grid, Breakpoints, & Flex Utilities
  • Komponen Esensial: Navbar, Hero, Cards, Modal, Accordion, Toast
  • Form Controls, Input Groups, dan Client-side Validation UX
  • Kustomisasi Tema, Utility Classes, dan Bootstrap Icons
  • Studi Kasus: Dashboard Portal Berita & Corporate Profile
MODUL 03 • 3 MINGGU Logika Utama

Modern JavaScript (ES6+), DOM Logic & Asynchronous

Menguasai bahasa pemrograman inti web. Dari manipulasi DOM interaktif hingga menangani data dinamis dari REST API.

  • ES6+ Features: Arrow Functions, Destructuring, Spread, Template Literals
  • DOM Manipulation, Event Bubbling, Delegation, & Form Handling
  • Asynchronous JavaScript: Promises, Async/Await, Fetch API
  • Working with JSON, LocalStorage, dan Session Management
  • Studi Kasus: Aplikasi E-Commerce Cart & Filter Produk Real-time
MODUL 04 • 3 MINGGU Ekosistem Modern

Introduction to React 18/19 & Component-Driven Dev

Melompat ke jenjang profesional dengan mempelajari library front-end paling banyak dicari oleh lowongan kerja startup saat ini.

  • Modern Tooling dengan Vite & Node.js Environment
  • JSX Syntax, Component Architecture, Props & Conditional Rendering
  • React Hooks Fundamental: useState, useEffect, useRef
  • Mengintegrasikan Bootstrap / React-Bootstrap dalam React App
  • Studi Kasus: Movie Database App terhubung ke API Eksternal
MODUL 05 • 1 MINGGU Karier & Deploy

Git/GitHub, CI/CD Deployment & Portfolio Polishing

Bukan cuma bisa nulis kode di laptop sendiri, tapi tahu cara kerja kolaborasi tim software engineer menggunakan Version Control.

  • Git Version Control: Branching, Commits, Pull Requests, Merge Conflict
  • Hosting & Deploying ke Vercel, Netlify, dan GitHub Pages
  • Auditing Kinerja Website dengan Google Lighthouse (Performance & SEO)
  • Menyusun GitHub Readme yang Elegan & Menarik Tech Recruiter
  • Output: Live Personal Portfolio Website Siap Dipamerkan
MODUL 06 • 1 MINGGU Penyaluran Kerja

Career Accelerator, CV ATS Review & Mock Interview

Persiapan mental dan strategi melamar pekerjaan dari mentor yang berpengalaman melakukan wawancara kandidat programmer.

  • Bedah CV Format ATS yang lolos saringan awal HRD
  • Optimasi Profil LinkedIn agar sering dihubungi Recruiter
  • Simulasi Live Coding Front-End (Pertanyaan Umum & Trik Menjawab)
  • Akses ke Jaringan Hiring Partner Abdul Malik Tech Academy
